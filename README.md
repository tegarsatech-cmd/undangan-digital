# Undangan Digital Pernikahan Adat Jawa
### Maroon Royal & Golden Cinematic Joglo Edition

Website undangan pernikahan digital bertema **Adat Jawa** bernuansa *Royal Maroon* dan *Gold*, dilengkapi animasi pembuka sinematik (*Cinematic Joglo Waterfall Motion*), musik latar, dan tata letak responsif untuk desktop maupun smartphone (mobile).

---

## ✨ Fitur Unggulan

- **Cinematic Opening Screen**: 
  - Gerbang pendopo Joglo dengan latar air terjun dan tirai pepohonan berornamen Jawa.
  - Efek partikel kelopak bunga melati emas berguguran.
  - Tombol artistik tunggal **"LIHAT UNDANGAN"** yang terintegrasi langsung dengan lukisan tangga Joglo dan efek pendaran emas saat disentuh.
  - Kontrol pembuka: tombol *Putar Ulang* dan pemutar *Musik*.
- **Gatekeeper Interaktif**: 
  - Konten utama undangan terkunci rapi hingga tamu menekan tombol pembuka.
- **Halaman Lengkap & Terstruktur**:
  1. **Cover / Hero**: Salam pembuka, nama kedua mempelai (*Aditya & Sekar*), ornamen Gunungan Wayang emas, serta tanggal acara.
  2. **Halaman Salam & Mempelai**: Ucapan *Assalamu'alaikum Wr. Wb.*, narasi filosofi wayang kulit, dan kartu foto solo kedua mempelai.
  3. **Halaman Rangkaian Acara**: Jadwal Akad Nikah dan Resepsi Pernikahan lengkap dengan waktu dan tempat.
  4. **Galeri Momen Bahagia**: Kisi galeri foto kenangan dengan bingkai klasik Jawa.
  5. **Lokasi & Denah Acara**: Alamat *Pendopo Agung, Solo, Jawa Tengah* beserta tombol navigasi Google Maps.
  6. **Tanda Kasih (Digital Gift)**: Opsi amplop digital dan rekening transfer / QRIS resmi.
  7. **Doa & Penutup**: Ucapan *Matur Nuwun* dan doa restu.
- **Editor Data Tamu & Pasangan (Floating Panel)**:
  - Tombol kelola data untuk mengubah nama pasangan, tanggal, alamat, unggah foto, serta mengganti lagu.
- **Desain Responsif**:
  - Disesuaikan secara presisi untuk kenyamanan membaca di ponsel Android, iPhone, tablet, hingga layar monitor desktop / ultrawide tanpa distorsi (*tidak lonjong dan tidak ter-crop*).

---

## 🚀 Cara Menjalankan

1. Clone repositori ini:
   ```bash
   git clone https://github.com/tegarsatech-cmd/undangan-digital.git
   ```
2. Buka file `index.html` langsung di browser favorit Anda, atau jalankan melalui local server:
   ```bash
   python -m http.server 8080
   ```
3. Akses melalui `http://localhost:8080/`.
